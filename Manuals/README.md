# Local Arroyo manuals

Keep official Arroyo Instruments protocol manuals in this directory as
read-only local evidence. PDF files are intentionally ignored until their
redistribution terms and the future repository visibility are reviewed.

The current library work uses `ArroyoComputerInterfacingManual.pdf`. The
derived, reviewable command catalog and item-by-item evidence belong in the
independent `pyarroyo` repository; library code and tests must not require this
PDF at runtime.
